# 📋 Changelog

All notable changes to NeoClaw will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-04-26

### 🎨 Theme
- Changed entire color scheme from red to golden yellow (#FBBF24)
- Updated dark mode and light mode themes
- Changed CLI palette to golden yellow
- Rebranded from OpenClaw to NeoClaw
- New ASCII art logo with golden theme

### ⚡ Execution Panel (New)
- Manus-style live task execution panel
- Step-by-step progress indicators with timing
- Live status dots (running/done/error)
- Artifact preview with Copy/Download buttons
- Duration tracking for each step

### 📦 Artifact Panel (New)
- Claude-style artifact viewer
- 3 view modes: Preview, Code, Split
- Tab interface for multiple artifacts
- Syntax highlighting with line numbers
- Font size controls (A- / A+)
- Version tracking
- Copy and Save buttons

### 📁 File Manager (New)
- Tree view with expandable directories
- Grid view for visual browsing
- Search across all files
- Sort by name, date, size, or type
- 30+ file type icons
- Show/hidden files toggle
- Download All feature

### 🧠 Memory Visualizer (New)
- See and manage AI memories
- 7 categories: Facts, Preferences, Context, Decisions, People, Projects, Todos
- Confidence indicators (1-5 dots)
- Inline editing
- Delete memories
- Search functionality
- Tag support
- Export as JSON

### 🕐 Task Timeline (New)
- Visual chronological event history
- Type filters: Messages, Tools, Files, Search, Code, Errors
- Date grouping: Today, Yesterday, specific dates
- Compact/Detailed toggle
- Duration tracking
- Export functionality

### 🏠 Device Control Hub (New)
- Smart TV control (power, volume, channel)
- Speaker control (play, pause, volume)
- Light control (brightness, color picker)
- Thermostat control (temperature, modes)
- Camera control (live view, recording)
- Lock control (lock/unlock)
- Computer control (screen mirror, files)
- Phone, Watch, Car support
- Quick Scenes: Movie Night, Good Morning, Goodnight, Away, Party, Focus
- Device scanning and discovery

### 💬 Chat UI
- Modern chat bubble layout (iMessage-style)
- User messages on right, AI messages on left
- Avatar support for both user and assistant
- Smooth message animations
- Code block headers with language labels
- Copy button for code blocks
- Typing indicator with bouncing dots
- Hover actions on messages
- Modern input bar with rounded corners

### 🔔 Notifications
- Browser notifications for task completion
- In-app toast notifications
- Animated slide-in from right
- Click to focus on chat
- Permission request on startup

### 📤 Export System
- Chat as Markdown
- Chat as JSON
- Workspace as ZIP
- Execution results export
- Memories export
- Timeline export
- Copy to clipboard

### ⌨️ Keyboard Shortcuts
- Ctrl+1: Execution Panel
- Ctrl+2: Artifacts Panel
- Ctrl+3: File Manager
- Ctrl+4: Memory Panel
- Ctrl+5: Timeline
- Ctrl+6: Device Hub
- Ctrl+0: Close Panel
- Escape: Close Panel
- Ctrl+K: Command Palette

### 💬 Welcome Screen
- Added "What can I help you with?" greeting
- Added keyboard shortcut hints for all 6 panels
- Suggestion buttons for quick actions
